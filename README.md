# Weight Training Tracker

A simple mobile-friendly training log for progressive overload.

## Features

- 5-day workout split preloaded
- Log weight and reps for every set
- Automatically compares current performance with the previous logged session
- Shows percentage change in weight, reps, and training volume
- Session notes after every workout
- Training history and exercise progress views
- Saves data locally in the browser using localStorage

## GitHub Pages

Publish from the `main` branch and `/ (root)` folder in **Settings → Pages**.
